# GeoFS-V3.9_Satellite-Imagery Release Notes - V1.0.2

## 🛠️ Bug Fixes & Reliability Enhancements

- Fixed an issue where the HUD panel failed to appear on simulator launch due to a race condition with Cesium layer initialization.
- Implemented robust simulator readiness polling, ensuring Cesium imagery layers and DOM are fully loaded before engine bootstrap.
- Replaced library-dependent DOM mounting with pure vanilla JavaScript `document.body.appendChild()` with high z-index priority (`9999999`).
- Added global **`Shift + M`** keyboard shortcut to quickly toggle the satellite imagery control panel and floating pill badge.
