# GeoFS-V3.9_Satellite-Imagery Release Notes - V1.0.1

## 🛠️ Maintenance & Refinement

- Standardized map selection to the four core high-resolution providers: **Google Satellite**, **Apple Maps Satellite**, **Bing Aerial**, and **Localhost Cache**.
- Restored native `Cesium.BingMapsImageryProvider` support with Bing Maps for Enterprise authentication.
- Optimized live in-memory Cesium layer swapping at index 0 for seamless real-time rendering.
- Enhanced viewport boundary clamping and persistent coordinate memory for the draggable glassmorphic HUD panel.
- Fully integrated with the unified GeoFS-V3.9 Design System styling and `V39_NOTIF` toast notifications.
