# GeoFS-V3.9_Satellite-Imagery Release Notes - V1.0.0

## 🚀 Initial Release

- Initial stable standalone release of the high-resolution satellite imagery switcher for GeoFS-V3.9.
- Implemented dynamic, in-memory Cesium imagery provider swapping without page reload.
- Focused 4-provider support matching the original script specification: **Google Satellite**, **Apple Maps Satellite**, **Bing Aerial**, and **Localhost Cache**.
- Standardized UI aesthetics with the unified **GeoFS-V3.9** Design System tokens (`rgba(26,26,26,0.94)` dark glassmorphism, `#ff9f05` amber accents, and Roboto typography).
- Integrated **GeoFS-V3.9** Core Library toast notifications (`V39_NOTIF`) with native fallbacks for boot, provider swaps, and error states.
- Implemented draggable panel with strict viewport boundary clamping and persistent coordinate memory (`localStorage`).
- Added collapsible, floating glassmorphic widget with minimize/expand state memory.
- Integrated persistent provider selection saved via `localStorage`.
- Enabled HD terrain elevation support with SRTM elevation data.
- Built-in automatic AdSense container removal for an ad-free experience.
