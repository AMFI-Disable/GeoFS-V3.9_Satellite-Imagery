# GeoFS-V3.9_Satellite-Imagery Release Notes - V1.1.0

## 🚀 Stable Bing Aerial HD Background Engine

- Promoted Bing Aerial HD engine to stable release **V1.1.0**.
- Implemented robust 10-second initialization delay ensuring GeoFS core services, Cesium viewer, and deferred assets finish loading before imagery injection.

- Standardized startup notification with `V39_NOTIF.success`.
- Persistent ad blocker removing AdSense containers.
