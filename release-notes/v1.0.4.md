# GeoFS-V3.9_Satellite-Imagery Release Notes - V1.0.4

## 🚀 Bing Aerial HD & Zero-UI Streamlining

- Streamlined the satellite imagery engine to exclusively use **Bing Aerial Ultra-Resolution** imagery and **SRTM HD terrain elevation meshes**.
- Completely eliminated on-screen panels, floating pills, and manual selectors for a clean, zero-clutter, distraction-free cockpit experience.
- Deeply integrated into GeoFS's native `geoIpUpdate`, `geofsStarted`, and `Cesium.BingMapsImageryProvider` lifecycle pipelines.
- Configured standardized ecosystem loaded notification toast (`GeoFS-V3.9_Satellite-Imagery V1.0.4 Loaded.`).
- Retained automatic background AdSense container removal.
